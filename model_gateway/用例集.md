# model_gateway 用例集(评审 + 回归)

> 评审用例与自动化测试一一对应;自动化入口:`cd model_gateway && uv run pytest -v`(25 用例)。

## 主流路径

| # | 用例 | 输入要点 | 预期输出 | 人工验收点 | 自动化 |
|---|---|---|---|---|---|
| 1 | 显式模型调用 | `model=mock-fast` + 1 条 user 消息 | 200;`metadata.routed_model=mock-fast`;content 含 `[mock:mock-fast]` | usage 三项自洽;metadata 五字段齐全 | test_correct.py |
| 2 | request_id 透传 | 自定义 `request_id=trace-abc-123` | 200;metadata.request_id 原样返回 | 追踪链路可用 | test_correct.py |
| 3 | 智能路由 × 5 种 capability | 分别传 low_latency / low_cost / high_quality / long_context / vision | 依次选中 mock-fast / mock-fast / mock-smart / mock-smart / mock-vision | 与能力表评分规则一致 | test_correct.py |
| 4 | 模型清单/能力表/健康检查 | GET /v1/models、/v1/capabilities、/health | 200;mock 模型 enabled=true,真实厂商 false | 与 config.yaml 一致 | test_correct.py |
