# 03_游戏制作 用例集

## 主路径用例

### TC-01 塔防游戏全流程
- **输入**: "我想做一个塔防游戏，中世纪风格，4种敌人3种塔，有金币系统"
- **预期输出**: 
  - 设计文档包含塔防类型、敌人/塔清单、地图布局
  - 模板匹配到 towerdefense/ 模板
  - 素材生成: 至少 4 种敌人 + 3 种塔 + 2 种子弹 + 1 个地面贴图
  - HTML5 游戏可运行，有塔防核心玩法
  - 视觉检测评分 ≥ 7
- **验收点**: 浏览器打开 index.html 可玩

### TC-02 贪吃蛇快速轮回
- **输入**: "做个贪吃蛇"
- **预期输出**:
  - 设计文档: 贪吃蛇类型
  - 模板匹配到 local/snake/ 模板
  - 素材生成: 蛇身/食物/背景
  - HTML5 贪吃蛇可玩
  - 视觉检测评分 ≥ 7
- **验收点**: 键盘方向键控制蛇移动

### TC-03 2048 益智游戏
- **输入**: "做个 2048 游戏，简约风格"
- **预期输出**:
  - 设计文档: 2048 类型
  - 模板匹配到 local/2048/ 模板
  - 素材生成: 数字方块 2-2048
  - HTML5 2048 可玩
  - 视觉检测评分 ≥ 7
- **验收点**: 方向键合并数字

## 异常路径用例

### TC-04 素材生成失败
- **输入**: "做个射击游戏，太空主题"
- **触发条件**: 素材生成服务不可用 / API 超时
- **预期输出**: 
  - 生成占位色块 PNG
  - checkpoint.json 标记素材生成失败
  - 游戏仍可运行（使用占位图）
- **验收点**: 游戏页面有彩色方块代替素材

### TC-05 视觉检测不通过
- **输入**: "做个打砖块"
- **触发条件**: 生成的游戏第一次截图评分 < 7
- **预期输出**:
  - 带反馈修复代码
  - 重试截图
  - 最多 2 轮修复
- **验收点**: 最终评分 ≥ 7 或 2 轮后交付

### TC-06 模板库未匹配
- **输入**: "我想做一个完全原创的跑酷游戏，角色是只猫"
- **触发条件**: 模板搜索无匹配
- **预期输出**:
  - 使用通用 HTML5 游戏骨架
  - 纯逻辑生成（无模板辅助）
  - checkpoint 标记 template_match: none
- **验收点**: 游戏可运行

## 回归测试

### RT-01 空输入
- **输入**: ""
- **预期输出**: 错误提示 "请提供游戏描述"
- **验收点**: 非零退出码，友好错误信息

### RT-02 重复运行
- **输入**: 同一描述运行两次，输出到不同目录
- **预期输出**: 两次独立产出，互不干扰
- **验收点**: 目录名不同，内容独立
