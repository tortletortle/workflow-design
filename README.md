# AI 工作流设计工作空间

这是一个用于**设计、调研和沉淀 AI 工作流**的工作空间。核心目标是:在搭建任何 AI 工作流之前,先盘点业界已有的开源轮子,做成可复用索引,避免重复造轮子、在合适的时候直接复用或借鉴。

## 当前范围

第一阶段聚焦 **LLM / Agent 编排**这一类开源项目 —— 即把大模型、Agent、检索、工具调用编排成可运行工作流的框架与平台。后续如有需要(多模态生成流水线、ML/数据科学流水线等),再按需扩列。

## 工作方式

1. **先查索引,再动手**:每次要设计新工作流,先翻 `开源项目索引.md` 的「选型决策表」,看是否已有成熟开源方案可复用或参考。
2. **按指南走流程**:照 `工作流设计指南.md` 的 6 步标准流程推进,要素清单逐项填齐。新工作流直接复制指南「附录 A」模板为该子目录的 `README.md`。
3. **索引随用随更**:发现新项目、或现有项目有重大变化(如 AutoGen 进入维护模式、Coze 开源),回到索引文件更新对应条目,并在文末「更新记录」追加一行。
4. **复用而非照搬**:索引只决定「选谁」,真正落地时仍要针对业务做裁剪与工程化;凡是所选项目原生能力能覆盖的不自研,业务专属逻辑封装成工具挂回框架。
5. **复用工作空间内的基础设施**:`model_gateway`(模型接入)与 `workflow_template`(Agent 循环 + 工具/MCP 分发)可直接作为新工作流的底座,不必从零搭建。

## 索引的说明与边界

- 索引里的 Stars、版本、活跃度均为**调研当时(2026-08)的近似值**,长期沿用前以仓库页为准。
- 许可证一栏区分「真·OSI 开源」与「fair-code / 源可见」(如 n8n、Dify、LobeChat、FastGPT),企业落地前务必复核条款。
- 商业 SaaS(如 coze.com / coze.cn 闭源版、Make)不在索引内;凡标「开源」的条目,均指其 GitHub 仓库公开、可自托管的版本。
