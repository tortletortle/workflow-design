### 🎯 核心功能

1. **智能分镜** - LLM自动将故事拆分成4格分镜
2. **角色卡生成** - 自动从故事提炼角色外貌卡
3. **提示词设计** - AI生成详细的图生图提示词
4. **多层质检**:
   - 提示词质检（检查是否覆盖所有要素）
   - 启发式质检（检查图片损坏、空白等）
   - 视觉质检（5维度评估图片质量）
5. **保形改图** - 质检失败时修正问题但保留角色风格
6. **图生图一致性** - 第一格作参考，后续格保持风格

## ⚙️ 参数调优

### 一致性模式强度

```yaml
image:
  consistency:
    enabled: true
    strength: 0.65    # 0-1, 越小越接近参考图
```

- `strength=0.3`: 严格保留参考风格，可能缺乏变化
- `strength=0.65`: **推荐**，平衡一致性和多样性
- `strength=0.9`: 允许更多变化，一致性较弱

### 并发与超时

```yaml
concurrency:
  design: 4          # 设计并发
  image: 2           # 生图并发（注意API限流）
  retries: 2         # 失败重试次数
```

## 🐛 故障排除

**问题**: 提示词包含垃圾文本
- 原因: 设计阶段模型返回低质量内容
- 解决: 增加 `concurrency.retries`

**问题**: 角色风格不一致
- 原因: 图生图未启用或强度不合适
- 解决: 检查 `consistency.enabled=true` 和调整 `strength`

**问题**: 生成超时
- 原因: 单格生成超过120秒
- 解决: 检查API响应速度或增加 `--timeout` 参数
