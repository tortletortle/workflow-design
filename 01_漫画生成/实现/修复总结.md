### 问题 2: HTTP 429 错误处理不当 ⚠️ 严重

**文件**: `app/client.py`  
**行号**: 70-77, 82-84, 103-110

**问题描述**:
- 遇到 429 配额耗尽时抛出通用 `RuntimeError`
- 错误地尝试降级到 chat 通道（配额是账号级别的，降级无意义）
- 浪费时间和资源

**修复前**:
```python
async def generate(self, prompt: str, size: str, model: str | None = None) -> bytes:
    try:
        return await self._via_images_api(prompt, size, model)
    except Exception:  # 捕获所有异常
        return await self._via_chat_api(prompt, size, model)  # 盲目降级

async def _via_images_api(self, prompt: str, size: str, model: str | None = None) -> bytes:
    # ...
    if resp.status_code >= 400:  # 不区分错误类型
        raise RuntimeError(f"images HTTP {resp.status_code}: {resp.text[:200]}")
```

**修复后**:
```python
async def generate(self, prompt: str, size: str, model: str | None = None) -> bytes:
    try:
        return await self._via_images_api(prompt, size, model)
    except QuotaExhaustedError:
        raise  # 配额错误直接抛出，不降级
    except Exception:
        return await self._via_chat_api(prompt, size, model)  # 只对其他错误降级

async def _via_images_api(self, prompt: str, size: str, model: str | None = None) -> bytes:
    # ...
    if resp.status_code == 429:  # 专门检测配额错误
        raise QuotaExhaustedError(f"images HTTP 429: {resp.text[:200]}")
    if resp.status_code >= 400:
        raise RuntimeError(f"images HTTP {resp.status_code}: {resp.text[:200]}")
```

**影响**:
- 配额管理失效
- 熔断机制无法触发
- 2个测试失败
