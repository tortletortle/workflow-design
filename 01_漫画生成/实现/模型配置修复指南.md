# 修复图像生成模型配置

## 问题
当前配置使用 `step-1-32k` 作为图像生成模型，但 StepFun API 不支持这个模型名称。

根据 StepFun 官方文档，文生图模型为：
- `step-image-edit-2` (推荐)
- `step-2x-large`

## 解决方案

### 1. 修改 .env 文件

将以下配置：
```bash
COMIC_IMAGE_MODEL=step-1-32k
```

改为：
```bash
COMIC_IMAGE_MODEL=step-image-edit-2
```

### 2. 修改 config.yaml 文件

将以下配置：
```yaml
image:
  fallback_models:
    - step-1-32k
```

改为：
```yaml
image:
  fallback_models:
    - step-2x-large
```

将以下配置：
```yaml
critic:
  vision_model: step-1-32k
```

改为：
```yaml
critic:
  vision_model: step-image-edit-2
```

### 3. 完整的 .env 配置示例

```bash
# StepFun 官方 API 配置
COMIC_BASE_URL=https://api.stepfun.com/v1
COMIC_API_KEY=你的API密钥

# 模型配置
COMIC_CHAT_MODEL=step-2-16k
COMIC_IMAGE_MODEL=step-image-edit-2  # 修改这里

# 视觉质检模型
COMIC_VISION_BASE_URL=https://api.stepfun.com/v1
COMIC_VISION_API_KEY=你的API密钥
COMIC_VISION_MODEL=step-image-edit-2  # 修改这里

# 图片编辑
COMIC_EDIT_BASE_URL=https://api.stepfun.com/v1
COMIC_EDIT_API_KEY=你的API密钥
COMIC_EDIT_MODEL=step-image-edit-2
```

### 4. step-image-edit-2 模型特点

根据官方文档：
- ✅ 支持文生图（/v1/images/generations）
- ✅ 支持图生图（/v1/images/edits）
- ✅ 最大提示词长度：512字符
- ✅ 支持尺寸：1024x1024（正方形）、768x1360、896x1184等
- ✅ 支持参数：steps、cfg_scale、seed、text_mode、negative_prompt

### 5. 注意事项

⚠️ **尺寸格式**: step-image-edit-2 使用 `height x width` 格式（不是 width x height）
- 项目配置使用 `1024x1024` 是正确的（正方形）

⚠️ **API端点**: 
- 标准端点：`https://api.stepfun.com/v1`
- Step Plan端点：`https://api.stepfun.com/step_plan/v1`（当前配置）

如果当前使用 step_plan 端点有问题，可以尝试改为标准端点。

### 6. 测试配置

修改后运行：
```bash
uv run python test_image_api.py
```

应该看到成功生成图片并保存到 test_output.png

### 7. 重新生成漫画

```bash
uv run python -m app.main doupo_test.txt --panels 4 -o out_doupo_test
```

## 模型对比

| 模型 | 用途 | 特点 |
|------|------|------|
| step-image-edit-2 | 文生图、图生图、图片编辑 | 推荐，支持 text_mode 优化文字场景 |
| step-2x-large | 文生图 | 支持更多尺寸选项 |
| ~~step-1-32k~~ | ❌ 不存在 | 这个模型不在 StepFun 图像生成 API 中 |
