   ```python
   import logging
   import json
   from datetime import datetime
   
   class JSONFormatter(logging.Formatter):
       def format(self, record):
           log_data = {
               "timestamp": datetime.utcnow().isoformat(),
               "level": record.levelname,
               "message": record.getMessage(),
               "module": record.module,
               "function": record.funcName,
           }
           if hasattr(record, 'extra'):
               log_data.update(record.extra)
           return json.dumps(log_data, ensure_ascii=False)
   
   def setup_logger(name: str, level: str = "INFO") -> logging.Logger:
       logger = logging.getLogger(name)
       logger.setLevel(level)
       
       handler = logging.StreamHandler()
       handler.setFormatter(JSONFormatter())
       logger.addHandler(handler)
       
       return logger
   ```

2. 在关键位置添加日志

### 任务 7：错误自动重试 ⏱️ 2 小时
**问题：** 标记了 `recoverable` 但没有自动重试

**修复内容：**
1. 在 `pipeline.py` 添加重试装饰器
   ```python
   from functools import wraps
   import asyncio
   
   def auto_retry(max_attempts: int = 3, delay: float = 2.0):
       def decorator(func):
           @wraps(func)
           async def wrapper(*args, **kwargs):
               last_error = None
               for attempt in range(max_attempts):
                   try:
                       return await func(*args, **kwargs)
                   except ComicError as e:
                       if not e.recoverable:
                           raise
                       last_error = e
                       logger.warning(
                           "auto_retry", 
                           extra={
                               "function": func.__name__,
                               "attempt": attempt + 1,
                               "error": str(e)
                           }
                       )
                       await asyncio.sleep(delay * (attempt + 1))
               raise last_error
           return wrapper
       return decorator
   
   @auto_retry(max_attempts=3)
   async def _call_with_retry(self, func, *args, **kwargs):
       return await func(*args, **kwargs)
   ```

2. 应用到关键操作
   ```python
   # 拆分阶段自动重试
   panels = await self._call_with_retry(split_story, chat, story, count, ...)
   ```

**验收标准：**
- ✅ 网络错误自动重试 3 次
- ✅ 配额错误不重试（立即失败）

### 任务 9：动态并发调整 ⏱️ 4 小时
**修复内容：**
```python
class AdaptiveConcurrency:
    def __init__(self, initial: int = 2, min_val: int = 1, max_val: int = 10):
        self.current = initial
        self.response_times: list[float] = []
    
    def adjust(self, response_time: float):
        self.response_times.append(response_time)
        if len(self.response_times) < 5:
            return
        
        avg = sum(self.response_times[-5:]) / 5
        if avg < 2.0 and self.current < self.max_val:
            self.current += 1  # 响应快，增加并发
        elif avg > 5.0 and self.current > self.min_val:
            self.current -= 1  # 响应慢，降低并发
```

**验收标准：**
- ✅ 并发度根据响应时间动态调整
- ✅ 日志记录调整过程
